Paint like Pollock

Creative coding, interactive tools, interface design

An interactive webpage using p5.js and the ml5.js library that allows its users to create illustrations by tracking different parts of their face. The user can adjust the brush size by opening and closing their mouth, and moving the brush by moving their head around.

Created under Clinton Van Anarm.

Facial movements as a form of creation, imagining alternate ways of illustration.

Process

Initially, I experimented with how blinking can be used as a mechanism to start and stop drawing. I created a very basic prototype, but soon it was clear that it was finicky and very difficult to use.

The facial recognition software couldn’t always pick up on the user blinking, especially when their head would be moving around in different angles, and that meant the user had very little control over the software and how the final drawing would appear.

From the first prototype, I felt that it was a little difficult to see where I was drawing on as the frame begins to be filled with brush strokes. I wanted to see if a separate canvas and camera screen would be easier to use, as it would allow the user to see themselves and the drawing clearly.
